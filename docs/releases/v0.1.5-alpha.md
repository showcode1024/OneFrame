## 自动更新

- 默认在启动时检查 GitHub Release，发现新版本时提示；也可在设置中关闭自动检查或手动检查。预览版会收到预览和正式版本，正式版仅接收正式版本。
- 用户可在应用内下载更新，下载时显示进度；应用核对文件 SHA-256、应用标识、版本号和固定发布签名后，交给 Android 系统确认安装。首次可能需要允许 OneFrame 安装应用。
- 自动检查需要能够访问 GitHub；安装并非静默完成，下载期间请保持应用运行。如果 GitHub 无法访问，也可以从发布页手动下载安装包。

## 其他说明

杜比视界 P5 系统直连解码仍属于实验功能，颜色和倍速流畅度需要在具体设备上验证；SDR 输出、P7 FEL 和 Atmos 的限制不变。

0.1.4 及更早版本尚不包含更新功能，需要先手动安装本版本。正式发布包使用相同签名，可直接覆盖升级。

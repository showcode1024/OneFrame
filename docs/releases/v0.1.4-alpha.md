## P5 播放诊断和性能实验

- 新增可选「轻量画面缩放」，降低 GPU 缩放负载，保留现有杜比元数据和 SDR 色彩映射；画面细节可能变化，对 CPU 解码瓶颈不保证有效。
- 新增默认关闭的「实验性系统直连解码」，优先尝试 MediaCodec 直连，不再对 P5 自动回退软解。P5 色彩可能严重偏差或无法播放，播放页会提示颜色未验证；关闭开关可恢复原策略。改设置后需重新打开视频。
- 播放诊断显示播放速度、实验和缩放状态，以及 P5 回退前的解码 API 与色彩标记。强制 CPU 软解优先级高于实验模式。

## 验证范围与限制

本版本不能保证 P5 硬解时杜比元数据得到保留，也不能保证 P5 色彩准确或倍速播放不掉帧。现有 libmpv / MediaCodec 路径可能无法将所需杜比数据传给渲染器；需要在目标设备上比较真实色彩和丢帧。

输出仍为 SDR / BT.709；Profile 7 FEL 完整重建尚未验证，Atmos 对象渲染尚未实现。

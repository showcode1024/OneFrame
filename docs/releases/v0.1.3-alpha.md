## 主要更新

- 支持保存、切换和移除多个 Emby 服务器账号；旧版已登录的账号会保留。
- 影片详情显示 Emby 返回的视频版本，可选择具体版本播放；播放前再次确认媒体源，避免误播其他文件。
- 片库首页新增继续观看、最近添加和媒体库；影片详情使用服务器提供的海报、背景图和元数据。
- 播放页面和播放信息显示当前选择的版本，播放进度使用选中的媒体源上报。

## 已知限制

- 当前播放原始文件，不自动转码；版本需要 Emby 将文件归并到同一影片才会显示在版本列表中。多个服务器的内容不会聚合到同一片库。
- 输出仍为 SDR / BT.709；Dolby Vision Profile 7 FEL 完整重建尚未验证，Atmos 对象渲染尚未实现。4K 软解性能取决于设备。
- 接口和播放器使用模拟器及模拟服务器测试，尚未在所有真实 Emby 服务器和设备上验证。

下载 Assets 中的 `OneFrame-0.1.3-alpha.apk` 安装。此版本与 0.1.2 正式发布包使用相同签名，可以直接覆盖升级。

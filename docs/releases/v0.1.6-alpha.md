## 自动更新

- 启动时检查 GitHub Release，发现新版本后提示；可在设置中关闭自动检查或手动检查。预览版会收到预览与正式版本。
- 发现新版本后可以打开官方 GitHub 下载链接；安装由浏览器和 Android 系统处理，并需要用户确认。应用不请求安装其他应用的权限。
- 更新对话框显示版本说明，较长的说明可以滚动。

自动检查和下载需要能够访问 GitHub。安装不能静默完成；首次安装可能需要在系统设置允许浏览器安装应用。

0.1.4 及更早版本尚不包含更新功能，需要先手动安装本版本。同签名的正式发布包可覆盖升级。

杜比视界 P5 系统直连解码仍属于实验功能，颜色和倍速流畅度需要在具体设备上验证；SDR 输出、P7 FEL 和 Atmos 的限制不变。

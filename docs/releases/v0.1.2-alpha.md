OneFrame 的首个 GitHub 云端构建预发布版本。

在下方 **Assets** 下载 `OneFrame-0.1.2-alpha.apk`，无需下载源代码压缩包。

支持 Android 8.0 及以上，APK 包含 arm64-v8a 和 x86_64。安装包由 GitHub Actions 从此版本标签的源代码构建，使用 OneFrame 专用固定签名；同时提供 SHA-256 校验文件。

### 安装与升级

这是首次使用 OneFrame 专用云端签名。此前通过聊天取得的本地开发签名包，以及 Actions 的临时 debug 包，不能被该 APK 直接覆盖。请先保存 Emby 服务器地址等必要配置，再自行卸载旧测试版、安装此包。切换后，未来使用同一项目签名且版本号递增的 Release 可以覆盖升级。

### 已有功能

- 原生 Kotlin / Compose 界面，Emby 账号登录、媒体库浏览与搜索。
- 本地文件、HTTP/HTTPS 视频和 Emby 直放。
- 系统解码优先，保留 CPU 软解；libmpv / libplacebo 色彩映射。
- 续播、音轨字幕切换、倍速、字幕延迟、横竖屏和播放诊断。

### 当前限制

画面仍输出 SDR / BT.709。HDR10 输出、Profile 7 FEL 完整重建、Atmos 对象渲染尚未实现。实体 MatePad 的 4K 性能和真实 Emby 服务器仍需联调，当前版本不能保证所有杜比片源都能正确、流畅播放。

更名后的本地验证包含 16 项单元测试和 5 项模拟器设备测试。此发布工作流还会独立执行 release 构建、单元测试、Lint、签名和 ZIP 对齐校验，通过后才发布安装包。

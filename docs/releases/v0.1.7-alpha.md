# OneFrame 0.1.7-alpha

面向手机和平板更新首页、片库、详情和播放器界面，并加入播放调节、外挂字幕和 Emby 收藏。

## 更新内容

- 重新设计首页、媒体库、详情和播放界面，保留 Emby 多服务器、同一影片的视频版本选择和续播功能。
- 播放时在画面左侧上下滑动调节亮度，或使用控制栏的亮度滑块；亮度只作用于当前播放窗口，不修改系统亮度。
- 在画面右侧上下滑动或使用音量滑块调节 Android 系统媒体音量。固定音量或外接设备可能需要在系统或设备上调节。
- 在「字幕与音轨」中添加本地文本字幕，例如 SRT、ASS、SSA 和 VTT；单个字幕文件最大 8 MB。Emby 播放支持选择服务器提供的当前视频源外挂文本字幕，以 SRT 格式获取。外挂图片字幕暂不支持。
- 可在 Emby 详情页收藏或取消收藏，首页展示服务器返回的收藏内容。

## 安装与限制

从 Release 的 Assets 下载 `OneFrame-0.1.7-alpha.apk`，使用 Android 系统安装。使用相同签名且版本号更低的 Release 可直接覆盖升级；早期开发签名或临时 CI debug 包需要先自行保存服务器信息，再卸载后安装。

本版本仍为 alpha，外挂字幕取决于服务器返回结果及其 SRT 接口；尚不支持 Emby Connect、跨服务器聚合、Live TV、离线下载、后台播放和画中画。真实设备和真实 Emby 服务器上的兼容性仍需验证。

Dolby Vision 输出目标为 SDR / BT.709，无法让 SDR 屏幕呈现 HDR 的物理亮度与色域。Profile 5 的软件处理可能导致高分辨率播放掉帧；实验性系统直连解码可能出现偏色或播放失败。Profile 7 FEL 完整重建尚未实现或验收，音频未实现 Atmos 对象渲染。具体画质和性能取决于片源与设备，不能保证所有杜比片源正确或流畅播放。

# OneFrame 0.1.8-alpha

本次主要调整界面，参考 Infuse 的内容展示方式，让 Emby 的真实封面和背景图成为视觉中心，并适配手机和平板。

## 更新内容

- 重新设计首页、海报墙、影片详情和播放控制界面；影片缺少图片时显示占位界面。
- 详情页以背景图展示影片信息，保留视频版本选择、收藏、播放和续播入口。
- 保留亮度、媒体音量、画面比例、播放控制锁定、字幕和音轨等已有播放功能。

## 安装与限制

从 Release 的 Assets 下载 `OneFrame-0.1.8-alpha.apk`，使用 Android 系统安装。使用相同签名且版本号更低的 Release 可直接覆盖升级；早期开发签名或临时 CI debug 包需要先保存服务器信息，再卸载后安装。

本版本仍为 alpha。海报和背景图取决于 Emby 服务器的媒体信息；真实设备和真实 Emby 服务器上的兼容性仍需验证。Emby 外挂文本字幕的可用性取决于服务器返回结果及其 SRT 接口，外挂图片字幕暂不支持。Emby Connect、跨服务器聚合、Live TV、离线下载、后台播放和画中画尚未实现。

Dolby Vision 输出目标为 SDR / BT.709，无法让 SDR 屏幕呈现 HDR 的物理亮度与色域。Profile 5 的软件处理可能导致高分辨率播放掉帧；实验性系统直连解码可能出现偏色或播放失败。Profile 7 FEL 完整重建尚未实现或验收，音频未实现 Atmos 对象渲染。具体画质和性能取决于片源与设备，不能保证所有杜比片源正确或流畅播放。
